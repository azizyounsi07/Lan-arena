🎮 LAN ARENA

Gaming Tournament & LAN Booking Platform

LAN ARENA is a web platform designed to connect gamers, esports organizers, and gaming venues through one unified booking ecosystem.

The platform allows users to discover gaming tournaments, register for competitions, and book LAN gaming sessions.

🚀 Main Features

* Browse and search gaming tournaments.
* Discover LAN gaming sessions.
* Register and manage reservations.
* User authentication and account management.
* Organizer dashboard to create events.
* Reservation management.

🛠️ Technologies

Frontend

* React.js
* Vite
* CSS

Backend

* Node.js
* Express.js
* Prisma ORM
* MySQL
* JWT Authentication

🎯 Project Objectives

* Simplify gaming tournament registration.
* Connect gamers with gaming venues.
* Support esports communities.
* Create a unified gaming booking platform.

🌍 Target Market

Initially focused on Tunisia, with the ambition to expand internationally.
